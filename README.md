# Household policies

This repository publishes the privacy notice and terms for Household, a
private, single-user personal-finance application. The `connections/` pages describe
Pepdevs Connections and its Gmail authorization, privacy and terms.

The site is static. It serves no client-side JavaScript, analytics, forms, cookies,
third-party assets, application secrets, or links to private repositories.

Run the public-surface check with:

```bash
node scripts/check-site.mjs
```
